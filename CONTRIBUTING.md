# Contributing

Gracias por ayudar a mejorar Market Structure Lab.

1. Creá un fork y una rama descriptiva.
2. Mantené los cambios enfocados y sin datos personales.
3. Ejecutá `node --check dist/app.js` antes de abrir un pull request.
4. Explicá el problema, la solución y cómo verificaste el cambio.

Las contribuciones deben preservar el enfoque educativo del proyecto. No se aceptan funciones que ejecuten operaciones, prometan rentabilidad o recopilen datos sin consentimiento explícito.
